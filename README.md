# YOLO Object Detection

A beginner-friendly computer vision project using Python and
Ultralytics YOLO for object detection.

## Technologies Used

- Python
- Ultralytics YOLO
- PyTorch
- OpenCV

## Features

- Detect objects in images
- Display object labels and confidence scores
- Save images with bounding boxes
